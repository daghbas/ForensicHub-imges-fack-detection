# testfackimage

تطبيق ويب مبني على Flask يسمح لك برفع صورة وتشغيل نموذج مدرَّب مسبقًا من ForensicHub
للكشف عن الصور المزيفة وإبراز مناطق التلاعب المحتملة.

## الإعداد

1. أنشئ بيئة بايثون (يفضل استخدام Python 3.10 أو أحدث).
2. ثبّت المتطلبات:

   ```bash
   pip install -r requirements.txt
   ```

3. ضع وزن النموذج داخل جذر المشروع باسم `best_model_1.pth` (يوجد ملف افتراضي صغير
   مكانه كعنصر نائب، استبدله بالوزن الحقيقي).
4. حدّث ملف `config.json` إذا كنت تستخدم نموذجًا مختلفًا أو ترغب بتعديل حجم الإدخال أو
   العتبة.
5. شغّل التطبيق:

   ```bash
   python -m testfackimage.app
   ```

سيعمل الخادم على العنوان `http://127.0.0.1:8000/`.

## المخرجات
- **احتمالية التلاعب**: يتم عرضها كنسبة مئوية.
- **خريطة التلاعب**: تدمج الخريطة الحرارية مع الصورة الأصلية لعرض المناطق الأرجح أن تكون
  مزيفة. إذا كان النموذج لا يعيد أقنعة، ستظهر رسالة توضح ذلك.

## المتطلبات
يمكنك استخدام ملف `requirements.txt` الموجود في جذر المستودع لتثبيت كل الاعتمادات أو إنشاء
ملف خاص بالمشروع يحتوي على الحد الأدنى:

```text
Flask
ForensicHub
Pillow
numpy
torch
torchvision
```

يفترض التطبيق أن مكتبة ForensicHub متاحة (إما عبر تثبيت الحزمة من هذا المستودع أو عبر `pip`).
